为什么这么判 id_no

探测器得分
名称 0.35 类型 0.10 值模式 0.40 字典 0.10 统计 0.05
  • 列名 id_no 命中内置别名表（身份证）→ 1.00
  • 类型 char(18) 与证件号长度一致 → 1.00
  • 值模式 命中 2,000 / 2,000 非空行，且 校验位通过率 100% → 1.00
  • 字典 前 6 位全部落在省份码表内 → 1.00
  • 统计 长度恒为 18、无空值，但基数高不具区分度 → 0.60
  • 采样 TABLESAMPLE(10 PERCENT)，未降级
  • 结论 0.35×1.00 + 0.10×1.00 + 0.40×1.00 + 0.10×1.00 + 0.05×0.60 = 0.980
身份证属于 强格式 + 校验位 类型，默认允许自动应用；但这次仍进人审，因为 warehouse 把这类阈值从 0.85 上调到了 0.99， 0.98 差 0.01 卡在门外——阈值按 catalog 可覆盖，见「敏感类型」那屏。
